# Sprint 02 — Fundação da Arquitetura

## Objetivo

Preparar a arquitetura modular do Wevvo ERP/PDV para refatoração segura do app.py.

## Escopo

- Criar estrutura base de organização.
- Preparar pastas para documentação, banco, testes e utilitários.
- Manter o sistema funcionando sem alterar regras de negócio.
- Iniciar a padronização para uso futuro de Blueprints Flask.

## Arquivos alterados

- docs/SPRINT_02_FUNDACAO_ARQUITETURA.md
- database/
- tests/
- utils/

## Como testar

1. Rodar o sistema normalmente.
2. Confirmar que o app.py continua funcionando.
3. Abrir a tela principal.
4. Testar Dashboard, Estoque, Receitas, Compras e Financeiro.
5. Verificar se nenhuma rota foi alterada.
